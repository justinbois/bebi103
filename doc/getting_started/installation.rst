.. _installation:

Installation
============

You can install bebi103 using pip. ::

	$ pip install --upgrade bebi103


Dependencies
------------

bebi103 has the following dependencies.

- Python 3.11 or newer
- NumPy_
- SciPy_
- Pandas_
- Polars_
- PyArrow_
- Numba_
- contourpy_
- tqdm_
- CmdStanPy_ 1.0.0 or higher
- xarray_
- ArviZ_ 1.0.0 or higher
- Bokeh_ 3.9.0 or higher
- Matplotlib_
- colorcet_
- HoloViews_
- scikit-image_
- Click_ 8.0.0 or higher
